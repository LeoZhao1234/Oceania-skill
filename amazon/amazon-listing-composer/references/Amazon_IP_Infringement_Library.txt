1. GLOBAL IP RULES
--------------------------------------------------
[HARD_BAN]
- Do NOT use competitor brand names in Title/Bullets/Description unless using the "Compatibility" format.
- [cite_start]Do NOT use competitor brand names in Backend Search Terms (This is trademark abuse). [cite: 16]
- [cite_start]Do NOT use "Official", "Genuine", "Authorized", or "OEM" unless you have explicit authorization. [cite: 16]

2. SAFE COMPATIBILITY TEMPLATES
--------------------------------------------------
[RULE] You may use a brand name ONLY to indicate compatibility.
[SAFE_FORMAT]
- "Compatible with [Brand] [Model]"
- "Replacement for [Brand] [Model]"
- "Fits [Brand] [Model]"
[UNSAFE_FORMAT]
- "[Brand] Case" (e.g., "iPhone Case" is risky; use "Case for iPhone")
- [cite_start]"[Brand] Filter" (e.g., "Dyson Filter" is risky; use "Filter for Dyson") [cite: 17]
